
# AI Data Analyst Agent 📊

An interactive Python application for analyzing
sales datasets using data science and machine learning.

## Features

- Upload CSV datasets
- Automatic data cleaning
- Interactive sales dashboard
- Revenue and product analysis
- Natural-language question answering
- Machine learning anomaly detection
- Download analysis reports

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Machine Learning

Uses the Isolation Forest algorithm to identify
unusual sales records based on numerical features.

## AI Assistant

Includes a rule-based natural-language assistant
that answers common questions about sales data.

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

4. Upload sample_sales.csv.
